# Lumbi Muchui Portfolio

Source code for [thel2.studio](https://thel2.studio), Lumbi Muchui's portfolio of climate-tech, mechatronics, electric-mobility, and direct-air-capture work.

## Technology

- Gatsby
- React
- styled-components
- Markdown and GraphQL for portfolio content

## Local development

```sh
npm install
npm run develop
```

The local site runs at `http://localhost:8000`.

## Production build

```sh
npm run build
npm run serve
```

## Content

- `content/jobs/` contains work experience.
- `content/featured/` contains featured case studies.
- `content/projects/` contains the project archive.
- `content/posts/` contains writing published under `/pensieve`.
